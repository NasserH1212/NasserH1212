## 📌 Featured Projects

### 📡 PulseWatch — Uptime Monitoring & Alerting
Checks HTTP endpoints, TCP ports and hosts on per-monitor schedules, confirms an outage before alerting, tracks incidents, and pushes live status to a React dashboard over WebSockets, with Telegram alerts. Built security-first: rotating refresh tokens with reuse detection, RBAC, rate limiting and request validation, with automated tests running in CI on every push.
[Backend](https://github.com/NasserH1212/pulsewatch-backend) · [Frontend](https://github.com/NasserH1212/pulsewatch-frontend)
`TypeScript` · `Node.js` · `Express` · `PostgreSQL` · `Prisma` · `Socket.io` · `React` · `Jest` · `GitHub Actions`

### 🛡️ [MiniSOC](https://github.com/NasserH1212/MiniSOC) — Local Defensive Security Monitoring
A local-only mini Security Operations Center for Windows. It reads local connection metadata, applies **rule-based detection** (port scans, SYN bursts, suspicious ports), stores alerts in **SQLite**, and presents them through an interactive dashboard.
`Python` · `Streamlit` · `psutil` · `Scapy` · `SQLite` · `Plotly`

### 🎓 [StuPilot](https://github.com/NasserH1212/StuPilot) — Bilingual Academic Organizer
An academic organization platform for university students, in Arabic and English.
`Next.js` · `TypeScript` · `PostgreSQL`

### 📄 [CreateCV](https://github.com/NasserH1212/createcv) — Bilingual ATS Resume Builder
A production web app for building ATS-friendly resumes with live preview, AI-assisted writing, and PDF export. Deployed with a custom domain.
`Node.js` · `Express` · `JavaScript`
